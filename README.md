# SmithViz
O   SmithViz é um projeto focado na visualização gráfica e interativa de impedâncias e suas caracteristicas quando empregadas em uma linha de transmissão, focando em aumentar a abstração, além de facilitar a resolução de problemas.

* Para rodar o projeto, acesse o link direto para o [SmithViz](https://well1ngt0nso.github.io/SmithViz/).

Em meu canal descrevo toda a teoria utilizada para desenvolver a lógica da carta + como levar isso para uma página web, a maioria dos meus projetos envolvendo alguma interface gráfica interativa faço em html + css + javascript (node.js ou flask ou nginx quando necessário server), tenho repositório de como utilizar o node.js e flask, esse projeto é baseao em meu outro repositório, seguindo a mesma lógica, mas para um gerador de redes Neurais ([NNVis](https://well1ngt0nso.github.io/NNVis/))
